# Reference, not asset

`mark-master-2048.jpg` is the render the author approved on 2026-08-26 (D-079).
It is kept for provenance only. **Do not ship it and do not derive from it.**

It is a JPEG: lossy, no alpha, ringing on every edge, black baked in. The real
asset is vector, rebuilt from measurements taken off this file and regenerated
by `make brand`. The mark occupies exactly 1024×1126 at offset (512, 461) here,
at scale 1 — which is what makes a pixel-for-pixel check against it possible.
